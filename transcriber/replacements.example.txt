# Автозамены в распознанном тексте.
# Формат: регулярное выражение => замена   (регистр не учитывается, \1 — группа)
# Порядок важен: правила применяются сверху вниз. Файл перечитывается на лету.

# --- типичные ошибки распознавания на телефонных записях (8 кГц) ---
\bключ ФСР\b => ключ ФСРАР
\b(Standarbird|Sunderbird|Sanderbird|Sandbird|Сандерб[её]рд|Тандерб[её]рд)\b => Thunderbird
\bмайл\b => Mail
\b([Рр])азторг => \1асторг
\bфиас\w* => ФИАС

# Сюда же — название своей компании, клиентов, номера точек: ASR часто пишет их по-разному.
# \b(вариант1|вариант2)\b => Правильное Название

# Проверить на следующих записях, прежде чем включать («войти в AnyDesk» -> «войти вами» / «войти в Анужды»):
# \bвойти (вами|в Анужды)\b => войти в AnyDesk
